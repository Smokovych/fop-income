# ФОП-дохід

Веб-програма для обліку доходу ФОП 3 групи (5%, без ПДВ). Сама тягне банківські виписки через API
**Monobank** і **ПриватБанку (Автоклієнт)**, визначає, які надходження є доходом, перераховує валюту
за курсом НБУ та рахує єдиний податок, військовий збір, ЄСВ, ліміт доходу і строки сплати.

## Що вміє

- **Автоматичне завантаження виписок** — у фоні кожні 60 хв (налаштовується) + кнопка «Оновити».
  Для Monobank можна увімкнути вебхук — операції приходять миттєво.
- **Класифікація операцій**: дохід / власні кошти / купівля-продаж валюти / повернення помилкових коштів /
  позики / повернення податків / повернення покупцю (зменшує дохід). Правила за ключовими словами
  редагуються, будь-яку операцію можна перекласифікувати вручну — ручна категорія не перезаписується.
- **Валютна виручка** перераховується за офіційним курсом НБУ на дату зарахування.
- **Огляд**: дохід за рік і квартал, графік по місяцях, використання річного ліміту, ЄП 5%, ВЗ 1%, ЄСВ,
  найближчі строки подання декларації та сплати.
- **Книга обліку доходів** — експорт у CSV (відкривається в Excel / Numbers / Google Sheets).
- Вхід за паролем, токени банків не показуються в інтерфейсі.

## Найпростіше: один файл у браузері

Файл `dist/ФОП-дохід.html` — повна програма в одному файлі. Двічі клацніть по ньому, і він відкриється
в Chrome, Safari або Firefox. Нічого встановлювати не треба.

- Monobank підключається токеном і оновлюється автоматично: при кожному відкритті та щогодини, поки вкладка відкрита.
- ПриватБанк не дозволяє браузерним програмам звертатися до свого API напряму, тому запити йдуть через «міст» —
  невеликий Google Apps Script у Google-акаунті користувача (код генерує сама програма, лише читання балансів і виписок).
  Виписки інших банків можна завантажити файлом (Excel або CSV).
- Дані зберігаються лише в цьому браузері. Робіть резервну копію (вкладка «Банки» → «Ваші дані»).

Зібрати файл заново після змін: `python3 standalone/build.py`.

## Серверна версія (автоматичний ПриватБанк, доступ з будь-якого пристрою)

Потрібен лише Python 3.10+ — сторонніх бібліотек немає.

```bash
python3 run.py            # http://localhost:8080
```

### На сервері (Docker)

```bash
cp .env.example .env      # задайте APP_PASSWORD і SECRET_KEY
docker compose up -d --build
```

Дані (SQLite) зберігаються у томі `fop-data`. Перед сервером поставте HTTPS-проксі
(Caddy / nginx / Cloudflare Tunnel) і встановіть `COOKIE_SECURE=1`, `PUBLIC_URL=https://…`.

## Підключення банків

**Monobank.** Відкрийте https://api.monobank.ua/, відскануйте QR-код у застосунку, скопіюйте токен
і вставте на вкладці «Банки». Рахунки з типом `fop` вмикаються автоматично; особисті картки — вимкнені
(можна ввімкнути вручну). Банк дозволяє 1 запит виписки на хвилину і до 31 доби за запит, тому
перше завантаження за рік триває ~12–15 хвилин — воно йде у фоні.

**ПриватБанк.** Приват24 для бізнесу → «Каталог послуг» → «Інтеграція (Автоклієнт)» → створіть
інтеграцію для отримання виписок, скопіюйте токен (та ID, якщо видано).

## Налаштування

На вкладці «Налаштування» вкажіть ПІБ і РНОКПП — надходження від вас самих не будуть рахуватися
доходом. Там же — дата, з якої тягнути виписки, ЄСВ (вимкніть, якщо звільнені) і податкові параметри
за роками. За замовчуванням закладено:

| Рік  | Мін. зарплата | Ліміт 3 групи | ЄСВ / міс | ЄП  | ВЗ |
|------|---------------|---------------|-----------|-----|----|
| 2025 | 8 000         | 9 336 000     | 1 760,00  | 5%  | 1% |
| 2026 | 8 647         | 10 091 049    | 1 902,34  | 5%  | 1% |

Строки: декларація — 40 днів після кварталу (з переносом з вихідного), ЄП і ВЗ — ще +10 днів,
ЄСВ — до 20 числа місяця після кварталу.

> Розрахунки допоміжні. Перед поданням декларації звіряйте суми з бухгалтером.

## Структура

```
app/
  server.py        HTTP-сервер, JSON API, авторизація
  sync.py          синхронізація виписок, фоновий планувальник, вебхук Monobank
  banks/monobank.py, banks/privatbank.py   клієнти банківських API
  classify.py      правила «дохід / не дохід»
  tax.py           ліміт, ЄП, ВЗ, ЄСВ, строки, книга обліку
  nbu.py           курси НБУ (кешуються)
  db.py            схема SQLite
static/            інтерфейс (HTML/CSS/JS без збірки)
tests/             тести + мок-сервер банків
```

## Тести і демо без справжніх токенів

```bash
python3 -m unittest discover -s tests -v

# демо з вигаданими даними:
python3 -m tests.mock_banks 8090 &
MONO_API=http://127.0.0.1:8090/mono PRIVAT_API=http://127.0.0.1:8090/privat \
NBU_API=http://127.0.0.1:8090/nbu MONO_MIN_INTERVAL_SEC=0 DB_PATH=/tmp/demo.sqlite3 python3 run.py
# далі на вкладці «Банки» введіть будь-який токен
```

## Що далі (за планом проєкту)

Імпорт даних з Електронного кабінету платника, подання декларації, нагадування (email / Telegram),
оплата податків із застосунку, мобільний застосунок і чат з бухгалтером.
