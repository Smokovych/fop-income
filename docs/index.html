    Облікові дані

    Дані беруться з Електронного кабінету платника через його офіційний API. Кабінет пускає лише з кваліфікованим електронним підписом (КЕП): відкрийте свій ключ і один раз налаштуйте міст.

    Крок 1. Ваш ключ (КЕП)

    Той самий файловий ключ, яким ви входите в Кабінет (напр. .pfx від monobank). Програма відкриває його тут, у браузері, і підписує лише ваш РНОКПП для входу.

    Для автоматичного оновлення інформації ви можете зберегти ключ на сервері

    🔒 Ключ і пароль залишаються лише в пам'яті цієї вкладки: програма їх не зберігає й нікуди не надсилає. До Кабінету йде тільки підписаний РНОКПП. Після перезавантаження сторінки ключ треба відкрити знову.

    Підключені банки

    Monobank — автоматично через API

    1. Відкрийте api.monobank.ua і відскануйте QR-код у застосунку monobank.
    2. Скопіюйте персональний токен і вставте нижче.

    Monobank дозволяє 1 запит виписки на хвилину, тому перше завантаження за рік триває ~12–15 хв. Не закривайте вкладку, поки йде завантаження. Далі виписка оновлюється при кожному відкритті програми та щогодини, поки вона відкрита.

    Інші банки — файл виписки

    1. У інтернет-банку вивантажте виписку рахунку ФОП за потрібний період у форматі Excel або CSV.
    2. Оберіть файл нижче. Повторне завантаження того ж періоду не створює дублів.

    ПриватБанк — автоматично через API
