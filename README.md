# ФОП-дохід

Веб-програма для обліку доходу ФОП 3 групи (5%, без ПДВ). Сама тягне банківські виписки через API
**Monobank** і **ПриватБанку (Автоклієнт)**, визначає, які надходження є доходом, перераховує валюту
за курсом НБУ та рахує єдиний податок, військовий збір, ЄСВ, ліміт доходу і строки сплати.

## Що вміє

- **Автоматичне завантаження виписок** — у фоні кожні 60 хв (налаштовується) + кнопка «Оновити».
  Для Monobank можна увімкнути вебхук — операції приходять миттєво.
- **Класифікація операцій**: дохід / власні кошти / купівля-продаж валюти / повернення помилкових коштів /
  позики / повернення податків / повернення покупцю (зменшує дохід). Правила за ключовими словами
  редагуються, будь-яку операцію можна перекласифікувати вручну — ручна категорія не перезаписується.
- **Валютна виручка** перераховується за офіційним курсом НБУ на дату зарахування.
- **Огляд**: дохід за рік і квартал, графік по місяцях, використання річного ліміту, ЄП 5%, ВЗ 1%, ЄСВ,
  найближчі строки подання декларації та сплати.
- **Книга обліку доходів** — експорт у CSV (відкривається в Excel / Numbers / Google Sheets).
- Вхід за паролем, токени банків не показуються в інтерфейсі.

## Найпростіше: один файл у браузері

Файл `dist/ФОП-дохід.html` — повна програма в одному файлі. Двічі клацніть по ньому, і він відкриється
в Chrome, Safari або Firefox. Нічого встановлювати не треба.

- Monobank підключається токеном і оновлюється автоматично: при кожному відкритті та щогодини, поки вкладка відкрита.
- ПриватБанк не дозволяє браузерним програмам звертатися до свого API напряму, тому запити йдуть через «міст» —
  невеликий Google Apps Script у Google-акаунті користувача (код генерує сама програма, лише читання балансів і виписок).
  Виписки інших банків можна завантажити файлом (Excel або CSV).
- Дані зберігаються лише в цьому браузері. Робіть резервну копію (вкладка «Банки» → «Ваші дані»).

Зібрати файл заново після змін: `python3 standalone/build.py`.

## На сервері: одні й ті самі дані на всіх пристроях

Та сама програма, але дані зберігаються на сервері: телефон, ноутбук і планшет бачать одне й те саме.
Запити до банків і Електронного кабінету ідуть через сервер, тож мости Google не потрібні: ПриватБанку достатньо токена, Кабінету — вашого ключа КЕП (підпис робиться в браузері, ключ на сервер не потрапляє).
Сервер **сам щогодини оновлює виписки** (і раз на добу — облікові дані з Кабінету, якщо збережено
ключ КЕП), навіть коли програма закрита на всіх пристроях. Це робить Node-воркер `app/node/worker.js`,
який виконує той самий код програми, що й браузер. Одночасно виписки тягне лише хтось один — сервер
або один із пристроїв (Monobank дозволяє 1 запит на хвилину). Зміни з різних пристроїв об'єднуються, а не затирають одна одну. Сервер сам робить
копію даних щонайменше раз на 6 годин (зберігаються останні 30).

### Render (рекомендовано)

1. Зареєструйтеся на https://render.com через GitHub.
2. **New → Blueprint →** підключіть репозиторій `fop-income`. Render прочитає `render.yaml` і створить
   сервіс у Франкфурті з постійним диском `/data` для бази (1 ГБ).
3. Введіть `APP_PASSWORD` — ваш пароль для входу (довгий, ніде більше не використовуваний) — і натисніть
   **Deploy Blueprint**. Render попросить картку: найменший платний сервіс $7/міс + диск $0,25/ГБ на місяць
   (безкоштовний тариф не підтримує диск, а без нього дані зникали б при кожному оновленні).
4. Через кілька хвилин адреса з'явиться вгорі сторінки сервісу (`https://fop-income-….onrender.com`).
   Надалі Render сам оновлює сервер після кожного коміту в `main`.
5. Відкрийте адресу, увійдіть паролем, на вкладці «Банки» → «Відновити з копії» завантажте
   резервну копію з браузерної версії.

### Railway

Також підтримується (`railway.json`): New Project → Deploy from GitHub repo → змінна `APP_PASSWORD`
→ Volume з точкою монтування `/data` → Settings → Networking → Generate Domain.

### Docker на своєму сервері

```bash
cp .env.example .env      # задайте APP_PASSWORD
docker compose up -d --build
```

Перед сервером поставте HTTPS-проксі (Caddy / nginx / Cloudflare Tunnel).

### Локально

```bash
python3 standalone/build.py   # збирає інтерфейс у docs/index.html
python3 run.py                # http://localhost:8080 (без APP_PASSWORD — лише з цього комп'ютера)
```

## Підключення банків

**Monobank.** Відкрийте https://api.monobank.ua/, відскануйте QR-код у застосунку, скопіюйте токен
і вставте на вкладці «Банки». Рахунки з типом `fop` вмикаються автоматично; особисті картки — вимкнені
(можна ввімкнути вручну). Банк дозволяє 1 запит виписки на хвилину і до 31 доби за запит, тому
перше завантаження за рік триває ~12–15 хвилин — воно йде у фоні.

**ПриватБанк.** Приват24 для бізнесу → «Каталог послуг» → «Інтеграція (Автоклієнт)» → створіть
інтеграцію для отримання виписок, скопіюйте токен (та ID, якщо видано).

## Налаштування

На вкладці «Налаштування» вкажіть ПІБ і РНОКПП — надходження від вас самих не будуть рахуватися
доходом. Там же — дата, з якої тягнути виписки, ЄСВ (вимкніть, якщо звільнені) і податкові параметри
за роками. За замовчуванням закладено:

| Рік  | Мін. зарплата | Ліміт 3 групи | ЄСВ / міс | ЄП  | ВЗ |
|------|---------------|---------------|-----------|-----|----|
| 2025 | 8 000         | 9 336 000     | 1 760,00  | 5%  | 1% |
| 2026 | 8 647         | 10 091 049    | 1 902,34  | 5%  | 1% |

Строки: декларація — 40 днів після кварталу (з переносом з вихідного), ЄП і ВЗ — ще +10 днів,
ЄСВ — до 20 числа місяця після кварталу.

> Розрахунки допоміжні. Перед поданням декларації звіряйте суми з бухгалтером.

## Облікові дані з Електронного кабінету

Вкладка «Облікові дані» бере дані з офіційного API приватної частини Кабінету
(`/ws/public_api/payer_card`). Кабінет пускає лише з КЕП: користувач відкриває свій файловий ключ
(.pfx, .jks, Key-6.dat) паролем просто в браузері, програма підписує РНОКПП за ДСТУ 4145
(бібліотеки jkurwa і gost89, зібрані в `standalone/vendor/kep.bundle.js` — див. `build-kep.sh`).
Ключ і пароль не зберігаються й нікуди не надсилаються; до Кабінету через міст Google Apps Script
іде лише підписаний РНОКПП.

## Структура

```
standalone/        інтерфейс — одна програма для всіх режимів
  app.js             облік, класифікація, податки, Monobank, імпорт файлів
  privat.js          ПриватБанк (через міст Google або через сервер)
  sync.js            ядро: дані, класифікація, курси НБУ, синхронізація Monobank (і в браузері, і на сервері)
  remote.js          режим сервера: вхід, спільні дані, злиття змін, замок синхронізації
  tax.js             вкладка «Облікові дані»: ключ КЕП, підпис, міст до Кабінету
  vendor/            бібліотека підпису ДСТУ 4145 для браузера (зібрана; вихідники й рецепт — kep-entry.js, build-kep.sh)
  commission.js      комісія еквайрингу з призначення платежу
  template.html, build.py   збирання в один файл → dist/ і docs/index.html
static/styles.css  стилі
app/
  server.py        HTTP-сервер: віддає docs/index.html, вхід, API
  store.py         спільне сховище стану з версіями та автоматичними копіями
  proxy.py         запити до Monobank, ПриватБанку, НБУ (лише читання)
  bg.py            фонове оновлення (щогодини), злиття з даними, зберігання ключа КЕП (зашифровано)
  node/worker.js   Node-воркер: виконує standalone/*.js — синхронізація банків, підпис РНОКПП, Кабінет
  sync.py, banks/, classify.py, tax.py, nbu.py, db.py   стара серверна модель (не використовується)
tests/             тести сервера + мок-сервер банків; merge.test.js — злиття змін
Dockerfile, render.yaml, railway.json   розгортання
```

## Тести і демо без справжніх токенів

```bash
python3 -m unittest discover -s tests -v
node tests/merge.test.js

# демо з вигаданими даними:
python3 -m tests.mock_banks 8090 &
MONO_API=http://127.0.0.1:8090/mono PRIVAT_API=http://127.0.0.1:8090/privat \
NBU_API=http://127.0.0.1:8090/nbu MONO_MIN_INTERVAL_SEC=0 DB_PATH=/tmp/demo.sqlite3 python3 run.py
# далі на вкладці «Банки» введіть будь-який токен
```

## Що далі (за планом проєкту)

Імпорт даних з Електронного кабінету платника, подання декларації, нагадування (email / Telegram),
оплата податків із застосунку, мобільний застосунок і чат з бухгалтером.
