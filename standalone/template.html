    Підключені банки

    Monobank — автоматично через API

    1. Відкрийте api.monobank.ua і відскануйте QR-код у застосунку monobank.
    2. Скопіюйте персональний токен і вставте нижче.

    Monobank дозволяє 1 запит виписки на хвилину, тому перше завантаження за рік триває ~12–15 хв. Не закривайте вкладку, поки йде завантаження. Далі виписка оновлюється при кожному відкритті програми та щогодини, поки вона відкрита.

    Інші банки — файл виписки

    1. У інтернет-банку вивантажте виписку рахунку ФОП за потрібний період у форматі Excel або CSV.
    2. Оберіть файл нижче. Повторне завантаження того ж періоду не створює дублів.

    ПриватБанк — автоматично через API

    ПриватБанк не відповідає програмам, відкритим у браузері, тому зв'язок іде через невеликий «міст» у вашому Google-акаунті. Він безкоштовний, працює цілодобово, знає лише ваш токен і вміє тільки читати баланси й виписки. Налаштування — один раз, близько 5 хвилин.

    1. Токен. Приват24 для бізнесу → «Каталог послуг» → «Інтеграція (Автоклієнт)» → «Підключити API». Поле IP-адрес залиште порожнім. У налаштуваннях застосунку на вкладці «Обмеження по сервісам» увімкніть обмеження й залиште лише «Отримання балансів і транзакцій за рахунками». Скопіюйте токен.

    2. Опублікуйте. Угорі праворуч «Розгорнути» (Deploy) → «Нове розгортання» → тип «Веб-застосунок». «Виконувати від імені»: Я; «Хто має доступ»: Усі. Натисніть «Розгорнути» й дозвольте доступ своєму акаунту (Google попередить, що застосунок не перевірено, — це ваш власний скрипт: «Додатково» → «Перейти»). Якщо змінюєте код уже розгорнутого мосту: «Керувати розгортаннями» → ✎ → «Версія»: «Нова версія» — адреса залишиться та сама.

    Усі дані та токени зберігаються лише в цьому браузері на цьому комп'ютері — нікуди не надсилаються, крім запитів до Monobank, НБУ та вашого мосту ПриватБанку в Google. Регулярно робіть резервну копію: якщо очистити дані браузера, вони зникнуть.
